# Default memory is a single memory.md, edited at compaction and refreshed into the prompt only on rebuild

The default memory Extension keeps one human-editable `memory.md` and exposes it as the `memory` Section. It updates the file only when Compaction happens (via the `compacted` notification), applying incremental edit operations (add / update / remove entries) derived from the entries that are about to leave the context, rather than rewriting the whole file after every Run, which gradually erodes detail through repeated paraphrase. The Section content only changes on a context rebuild (startup or Compaction), so the system prompt stays byte-stable between compactions and the prompt cache survives; facts learned since the last rebuild are still present verbatim in the recent Timeline, so nothing is lost. Search-based recall was deferred; the kernel's Recall mechanism remains for such replacement Extensions.
